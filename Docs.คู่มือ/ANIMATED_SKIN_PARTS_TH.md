# แอนิเมชันส่วนยานของสกิน — 14 ตุลาคม 2026

## สิ่งที่เปลี่ยน

สกินทั้ง 15 แบบใช้โครงภาพ 2D แบบแบ่งน้ำหนักการเคลื่อนไหว ไม่ใช่การเลื่อน/หมุนรูปทั้งลำ:

- ปีกซ้ายและขวาหมุนรอบจุดพับ ขณะที่แกนกลางช่วงบนอยู่นิ่ง
- บริเวณเครื่องยนต์ท้ายลำเลื่อนขึ้นลงเป็นจังหวะแยกจากปีก
- สกินแนวแมลง/มังกร/ผีเสื้อ/พระจันทร์เคลื่อนไหวมากกว่ายานเครื่องจักร
- หน้าคลัง ร้านสกิน ล็อบบี้ ห้องรอ และยานในสนาม ใช้สูตรการเคลื่อนไหวเดียวกัน
- ไอพ่นคำนวณจุดยึดตามเครื่องยนต์ที่ขยับ ไม่ค้างอยู่ตำแหน่งเดิม

เป็นการขยับส่วนต่าง ๆ ของ mesh บนภาพ 2D เดิม ไม่ใช่โมเดล 3D หรือไฟล์ภาพใหม่แยกปีกออกจากลำตัว ขอบเชื่อมใช้การผสมน้ำหนักเพื่อไม่ให้เกิดช่องโหว่บนภาพ

## ความปลอดภัยต่อการเล่น

- ไม่ขยับ Transform หลัก/Collider/จุดยิง ไม่เปลี่ยน HP ความเร็ว ดาเมจ หรือรหัสสกิน
- SpriteRenderer เดิมยังเก็บขนาดและสถานะให้ระบบอื่นอ่านได้ ส่วนภาพที่แสดงใช้ MeshRenderer ลูก
- ภาพใหม่ตามสี ความโปร่งใส การกลับด้าน สถานะตาย และล่องหนของยาน
- UI ไม่เพิ่มตัวรับคลิก และใช้การตัดขอบเดิมของ Canvas
- เมื่อเปลี่ยนกลับไปใช้ภาพที่ไม่ใช่สกิน จะปิดโครงแอนิเมชันและคืนภาพเดิม
