## เฟส 2 — ห้อง 2–10 คน (ตัวใครตัวมัน / FFA)
**วิธีใช้**
- ห้องรอ: Host กดป้าย `1 VS 1 >>` มุมซ้ายบน วนเป็น FFA 4P / 6P / 8P / 10P (ห้องจะรับคนได้ตามนั้น)
- ห้อง FFA: การ์ดใหญ่ 2 ใบเปลี่ยนเป็นช่องเล็ก 10 ช่อง, Host เริ่มได้เมื่อมี 2 คนขึ้นไปและทุกคน READY
- เปิด BOT ในห้อง FFA = ช่องว่างจะเติมเป็นบอทจนเต็ม
- Host แตะชื่อผู้เล่นคนอื่น 2 ครั้งภายใน 3 วินาที = เตะออก (เข้าห้องเดิมไม่ได้อีก)
- หน้าหลัก: ปุ่ม `1 BOT / 3 / 5 / 9 BOTS` (ใต้ปุ่มความยาก) เลือกจำนวนบอทในโหมด VS BOT → ใช้ทดสอบ FFA 10 ลำได้คนเดียว

**ในเกม**
- เกิดเป็นวงรอบสนาม แต่ละคนได้ช่องของตัวเอง หันหน้าเข้ากลาง
- คะแนนบนจอ: `YOU 2 / RANK #3/8 / LEAD 4`
- ตารางคะแนนย่อมุมขวา แตะเพื่อเปิดตารางเต็ม (อันดับ / ชื่อ / Kill / ตาย)
- Kill Feed ใต้มินิแม็พ (ใช้ทั้ง 1v1 และ FFA)
- คนหลุดระหว่างแข่ง: คนที่เหลือเล่นต่อ (1v1 ยังยกเลิกแมตช์แบบเดิม) เหลือไม่ถึง 2 ลำ = จบแมตช์
- Host หลุด: Host คนใหม่ควบคุมบอทต่ออัตโนมัติ
- จบเกม: หน้าผลจัดอันดับ + MVP เหรียญตามอันดับ (ที่ 1 = เท่าชนะ 1v1, ที่สุดท้าย = เท่าแพ้)
- คนเยอะ: ลดความถี่ส่งตำแหน่ง (10 คน ≈ 5 ครั้ง/วินาที) และเดาตำแหน่งจากความเร็วให้ยานยังลื่น

**ไฟล์**
| ไฟล์ | หน้าที่ |
|---|---|
| GameplayManager.Multi.cs (ใหม่) | จุดเกิดวงรอบ, ตารางคะแนน, Kill Feed, คนหลุด, หน้าผลจัดอันดับ, ความถี่ส่งข้อมูล |
| LobbyManager.Roster.cs (ใหม่) | ช่องนักบิน 10 ช่องในห้องรอ + เตะผู้เล่น |
| MatchRules.cs | จำนวนคน (Humans), ตาย (Deaths), ตารางคะแนนรวมบอท, ความถี่ส่งข้อมูล |
| LobbyManager.RoomSettings.cs | ปุ่มโหมด/จำนวนคน |
| LobbyManager.cs | เริ่มเกมได้ 2+ คน, เติมบอทเต็มห้อง |

**ยังไม่ได้ทำในเฟสนี้**: ขยายขนาดสนามตามจำนวนคน (ต้องแก้แม็พ) / ไอเทมในแม็พ (เฟส 5)

**เช็คลิสต์ทดสอบ**
1. VS BOT + 9 BOTS → เกิดเป็นวง, ตารางคะแนน, Kill Feed, หน้าผลจัดอันดับ
2. ห้องออนไลน์ FFA 4P + BOT → เพื่อน 1 คน + บอท 2
3. FFA กำลังเล่น ให้เพื่อนปิดแอป → เกมไม่ถูกยกเลิก ยานเพื่อนหายไป
4. Host ออกกลางแมตช์ FFA ที่มีบอท → บอทยังขยับ
5. ห้อง 1 VS 1 แบบเดิม → ทุกอย่างเหมือนก่อน
6. เตะผู้เล่นในห้องรอ

## เฟส 3 — โหมดทีม (2v2 / 3v3 / 4v4 / 5v5)
**วิธีใช้**
- ห้องรอ: Host กดป้ายโหมดวน `1 VS 1 → FFA 4P → TEAM 2v2 → FFA 6P → TEAM 3v3 → ... → TEAM 5v5`
- แถวบน = ทีม BLUE แถวล่าง = ทีม RED เข้าห้องแล้วจะถูกใส่ทีมที่คนน้อยกว่าอัตโนมัติ
- แตะช่องของตัวเอง = ย้ายทีม (ต้องยังไม่กด READY และอีกทีมยังไม่เต็ม)
- ตอนกดเริ่ม Host จัดทีมให้สองฝั่งต่างกันไม่เกิน 1 คน / เปิด BOT = เติมบอทให้ครบทั้งสองทีม
- หน้าหลัก: ปุ่มจำนวนบอทมี `TEAM 2v2 / 3v3 / 5v5` ด้วย (เราอยู่ BLUE กับบอทเพื่อน)
- ห้องที่ตั้งเป็นทีมแต่รวมแล้วไม่ถึง 4 ลำ จะเล่นแบบตัวใครตัวมันแทน

**ในเกม**
- BLUE เกิดฝั่งล่าง (หันขึ้น) RED ฝั่งบน (หันลง) เกิดใหม่ก็ฝั่งทีมตัวเอง
- ยิงเพื่อน/สกิลโดนเพื่อนไม่เสียเลือด (กระสุนทะลุผ่านเพื่อน) มิสไซล์ไม่ล็อกเพื่อน บอทไม่ยิงเพื่อน
- เป้าหมาย = Kill ที่ตั้ง x คนต่อทีม (เช่น 2v2 ตั้ง 5 Kill = ทีมแรกที่ถึง 10 ชนะ)
- คะแนนบนจอ `BLUE 7 : 5 RED / YOU: BLUE`, ชื่อเหนือยานเป็นสีทีม แถบเลือดเพื่อนสีเขียว
- เรดาร์: เพื่อนจุดเขียว (เห็นตลอด) ศัตรูจุดแดง (เห็นเฉพาะในระยะ)
- ทีมหนึ่งไม่เหลือใครออนไลน์ = อีกทีมชนะ
- หน้าผล: VICTORY / DEFEAT / DRAW ทั้งทีม ทีมชนะได้เหรียญเท่าชนะ 1v1 ทีมแพ้ได้เท่าแพ้ เสมอ 0

**ไฟล์**
| ไฟล์ | สิ่งที่เพิ่ม |
|---|---|
| MatchRules.cs | TeamOf / IsAlly / TeamKills / AssignTeams (แบ่งทีม) |
| BulletController.cs, SkillController.cs | ไม่โดนเพื่อน (ใช้ MatchRules.IsAlly) |
| BotController.cs | ไม่เล็งเพื่อน |
| GameplayManager.Multi.cs | จุดเกิดทีม, คะแนนทีม, หน้าผลทีม |
| LobbyManager.Roster.cs | แถวทีม, ย้ายทีม |
| RadarMinimap.cs | สีเพื่อน/ศัตรู |

ปิดโหมดทีม: `FeatureFlags.Teams = false`

**เช็คลิสต์ทดสอบ**
1. หน้าหลักเลือก TEAM 5v5 แล้วกด VS BOT → เกิดสองฝั่ง ยิงเพื่อนไม่โดน คะแนนทีม หน้าผลทีม
2. ห้องออนไลน์ TEAM 2v2 + BOT กับเพื่อน 1 คน → เพื่อนย้ายทีมได้ บอทเติมให้ครบ 2v2
3. ห้อง TEAM 3v3 ไม่เปิดบอท มีคน 4 คน ให้ 3 คนอยู่ BLUE → กดเริ่มแล้วถูกจัดเป็น 2 ต่อ 2 อัตโนมัติ
4. 1 VS 1 และ FFA ยังเหมือนเดิม

## เฟส 4 — เลเวล ภารกิจ ล็อกอิน Achievement โปรไฟล์ ประวัติ
**หน้าหลัก**
- ป้าย `LV` ข้างกล่องโปรไฟล์ + แถบ XP ใต้ชื่อ
- ปุ่ม `MISSIONS` และ `PROFILE` (แทนข้อความ READY FOR BATTLE?) ปุ่ม MISSIONS มีวงแดงบอกจำนวนรางวัลที่รอรับ
- เปิดเกมวันใหม่ = เด้งหน้ารับรางวัลล็อกอินให้อัตโนมัติ

**กติกา (แก้ตัวเลขได้ใน Progression.cs)**
- XP ต่อแมตช์ = 20 + Kill x 6 + ชนะ 40 / เสมอ 20 (+ โบนัสอันดับ FFA) เล่นกับบอทออฟไลน์ได้ 60% / บทสอนไม่นับ
- XP ที่ต้องใช้ขึ้นเลเวล = 100 + 50 x (เลเวล - 1) สูงสุดเลเวล 50 ขึ้นเลเวลได้เหรียญ 50 + เลเวล x 10
- ภารกิจรายวัน 3 ข้อ (สุ่มจาก 8 แบบ ทุกคนได้ชุดเดียวกันในวันเดียวกัน) + รายสัปดาห์ 3 ข้อ กดรับได้เหรียญ + XP
- รางวัลล็อกอิน 7 วัน: 30 / 40 / 50 / 60 / 80 / 100 / 200 (ขาดวัน = เริ่มวันที่ 1 ใหม่)
- Achievement 12 อัน ปลดแล้วได้ฉายา + ฉายาตามเลเวล (5, 10, 20, 30, 50) เลือกโชว์ได้ในหน้า PROFILE
- หน้า PROFILE: สถิติ (แมตช์ ชนะ แพ้ เสมอ อัตราชนะ Kill ตาย K/D สตรีค) + ประวัติ 6 แมตช์ล่าสุด (เก็บ 15)
- หน้าผลแมตช์มีบรรทัด `+XP / LEVEL UP / ACHIEVEMENT / รางวัลรอรับ`
- ในห้องรอ ชื่อผู้เล่นมี `Lv12` นำหน้า

**เก็บข้อมูลที่ไหน**
- Firebase: `users/{uid}/progress_json` (JSON ก้อนเดียว) + `users/{uid}/level` และ `xp` แยกไว้
- ในเครื่อง: PlayerPrefs `progress_{uid}` (ใช้ตอนไม่มีเน็ต) เลือกก้อนที่บันทึกล่าสุด

**ไฟล์**: Progression.cs (ใหม่ กติกา+ข้อมูล), LobbyManager.Progress.cs (ใหม่ หน้าจอ), GameplayManager.Progress.cs (ใหม่ ส่งผลแมตช์), FirebaseManager.cs (LoadProgressJson / SaveProgressJson)

**สวิตช์**: `Progression` (ทั้งระบบ), `Missions`, `DailyLogin`, `Achievements`

**เช็คลิสต์ทดสอบ**
1. เข้าเกม → หน้ารับรางวัลล็อกอินเด้ง กด DAY 1 → เหรียญเพิ่ม 30
2. เล่น VS BOT 1 ตา → หน้าผลมี +XP, กลับล็อบบี้ แถบ XP ขยับ ภารกิจ PLAY3 เป็น 1/3
3. หน้า PROFILE → สถิติ/ประวัติแมตช์ขึ้น, Achievement First Blood ปลด, กด CHANGE TITLE
4. ปิดเกมเปิดใหม่ → ข้อมูลยังอยู่ (ดูใน Firebase users/{uid}/progress_json)
5. ห้องรอ → ชื่อมี Lv นำหน้า

## เฟส 5 — ตีบวกยาน / ไอเท็ม / ร้านค้า / กล่องสุ่ม
**เข้าใช้**: ปุ่ม `WORKSHOP` ด้านบนหน้าหลัก (ข้างปุ่ม SETTINGS) มี 3 แท็บ เลือกยานด้วยปุ่ม `< >`

**UPGRADE (ตีบวกยาน)**
- ตีบวกได้ 3 ค่า: HULL (HP +4%/ขั้น), ENGINE (SPD +2.5%/ขั้น), WEAPON (ATK +4%/ขั้น)
- เพดานตามราคายาน: Nebula Ghost (ฟรี) +5, Comet Crusher +8, Stellar Striker (แพงสุด) +10
- SAFE = สำเร็จ 100% ราคา 200 x (ขั้นถัดไป) / CHANCE = ครึ่งราคา โอกาสสำเร็จ 95% ลดลงขั้นละ 7% (ต่ำสุด 30%) ล้มเหลวเสียเหรียญแต่ขั้นไม่ลด

**ITEMS (ไอเท็ม)**
- ช่องใส่ไอเท็ม: ยานฟรี 1 ช่อง, ยานกลาง 2, ยานแพง 3 / แตะช่องเพื่อถอด
- ไอเท็ม 8 แบบ: Armor Plating (HP), Ion Thruster (SPD), Plasma Cannon (ATK), Rapid Loader (ยิงเร็วขึ้น), Skill Capacitor (คูลดาวน์สกิลลด), Nano Repair (ฟื้นเลือดเมื่อไม่โดนยิง 3 วิ), Aegis Core (กันตัวหลังเกิดนานขึ้น), Siphon Module (ฆ่าได้ฟื้นเลือด)
- ตีบวกไอเท็มได้ถึง +5 (แบบมีโอกาส ล้มเหลวเสียเหรียญแต่ไม่ลดขั้น)

**SHOP (ร้านค้า)**
- ซื้อไอเท็ม COMMON 400 / RARE 900 (EPIC ได้จากกล่องเท่านั้น)
- SUPPLY CRATE 600: เหรียญ 200–500 45% / COMMON 35% / RARE 15% / EPIC 5% (แสดงโอกาสบนจอ)

**ในเกม**: ค่าพลังรวม (ตีบวก + ไอเท็ม) ใช้กับยานของเราตอนเกิด / ห้องรอมีปุ่ม `UPGRADES ON/OFF` (Host) ปิด = ทุกคนใช้ค่าพื้นฐาน (แข่งยุติธรรม) / บอทไม่มีตีบวก

**เก็บข้อมูล**: Firebase `users/{uid}/economy_json` + ในเครื่อง, หักเหรียญด้วย Transaction (`FirebaseManager.SpendCoins`) เงินไม่พอจะไม่หัก

**ไฟล์**: Economy.cs (ใหม่ กติกา/ราคา/ไอเท็ม), LobbyManager.Workshop.cs (ใหม่ หน้าจอ), PlayerController.Items.cs (ใหม่ ผลในเกม), FirebaseManager.cs (LoadUserJson / SaveUserJson / SpendCoins)

**สวิตช์**: `Upgrades` (ตีบวก), `Items` (ไอเท็ม/ร้าน/กล่อง)

**รูปที่ต้องทำ**: ดู `ART_TODO_TH.md`

**เช็คลิสต์ทดสอบ**
1. WORKSHOP → UPGRADE กด SAFE ที่ HULL → เหรียญลด ขั้นขึ้น +1 / กด CHANCE หลายครั้ง มีล้มเหลวบ้าง
2. SHOP ซื้อ Armor Plating → ITEMS กด EQUIP → แท็บ UPGRADE บรรทัด IN BATTLE HP เพิ่ม
3. เปิด SUPPLY CRATE → ได้เหรียญหรือไอเท็ม
4. เล่น VS BOT → HP ยานเราในเกมสูงขึ้นตามที่ตีบวก
5. ห้องรอ Host กด UPGRADES OFF → ในเกม HP กลับเป็นค่าพื้นฐาน
6. เหรียญไม่พอ → ขึ้นข้อความ Not enough และเหรียญไม่ถูกหัก

## เฟส 6 — แรงค์ / MMR / ตารางอันดับ / ฤดูกาล
**หน้าหลัก**: ปุ่ม `RANKED  GOLD 1320` (แถวล่างขวา) → หน้าแรงค์: ระดับ, MMR, คะแนนถึงแรงค์ถัดไป, สถิติฤดูกาล, รางวัลจบฤดูกาล, ปุ่ม `FIND RANKED MATCH` และ `LEADERBOARD`

**แมตช์แรงค์**
- กด FIND RANKED MATCH = หาห้องแรงค์ที่รออยู่ ไม่มีจะสร้างห้องใหม่ (ชื่อห้องขึ้นต้นด้วย R) แล้วรอคู่แข่ง
- กติกาตายตัว: 1 VS 1, 5 Kill / 5 นาที, เปิดอันตรายในแม็พ, ปิดตีบวก/ไอเท็ม, ไม่มีบอท, Host แก้ค่าไม่ได้ (เปลี่ยนแม็พได้)

## เฟส 7B — โหมดเกมใหม่ + Campaign + หินลอยรอบเสา
**เลือกโหมด**
- ออนไลน์: ห้องรอมีปุ่มโหมด (ขวาของหัวข้อเลือกแม็พ) Host กดวน DEATHMATCH → KING OF THE HILL → STAR HUNT → BATTLE ROYALE → SURVIVAL (ห้องแรงค์ล็อกเป็น DEATHMATCH)

| โหมด | กติกา |
|---|---|
| KING OF THE HILL | วงกลางสนาม ยืนในวงคนเดียว (หรือทีมเดียว) ได้ 1 คะแนน/วิ มีคนอื่นอยู่ด้วย = CONTESTED ไม่มีใครได้ เป้า = Kill ที่ตั้ง x 15 (3→45) วงเปลี่ยนสี เขียว=เรายึด แดง=ศัตรูยึด เหลือง=แย่งกัน |
| STAR HUNT | ดาวสีทองเกิดทุก 2.5 วิ (สูงสุด 6) บินชนเก็บ +1 ตายแล้วดาวหล่น 1 ดวง เป้า = Kill ที่ตั้ง x 3 |
| SURVIVAL | คนจริงร่วมทีมกันสู้บอทเป็นระลอก 10 ระลอก (บอทเพิ่มขึ้นและเก่งขึ้นเรื่อยๆ ระลอก 5 และ 10 มีบอส) คนละ 3 ชีวิต รอดครบ 10 ระลอก = ชนะ หมดชีวิตทุกคน = แพ้ / เหรียญ 15 ต่อระลอก +100 ถ้ารอดครบ |
| BATTLE ROYALE | 1 ชีวิต วงสีฟ้าหดจากวินาทีที่ 15 ถึง 80% ของเวลา อยู่นอกวงเสียเลือด (ยิ่งวงเล็กยิ่งแรง) รอดคนสุดท้ายชนะ จัดอันดับตามลำดับการตาย |
| CAMPAIGN | เล่นคนเดียว 5 ด่าน (Campaign.cs) มีเนื้อเรื่องภาษาไทยตอนเริ่มด่าน คน 3 ชีวิต ด่าน 5 ต้องทำลายบอส DREADNOUGHT ผ่านด่านครั้งแรกได้ 150/250/350/500/1000 เหรียญ (เล่นซ้ำได้ 25%) กดเล่นต่อหลังผ่าน = ไปด่านถัดไป |

- ตารางคะแนนและหน้าผล: โหมดยึดจุด/เก็บดาวแสดง SCORE แทน KILLS

**สวิตช์**: `GameModes`, `PillarRocks`

## เฟส 8 — เพื่อน / สถานะออนไลน์ / ชวนเข้าห้อง / แชท / กิลด์
**หน้าหลัก**: แถว MISSIONS / PROFILE / `SOCIAL` (วงแดง = คำขอเป็นเพื่อน + คำชวนที่รออยู่) → หน้าต่าง 4 แท็บ
- **FRIENDS**: โค้ดเพื่อนของเรา 8 ตัว (กด COPY) / ใส่โค้ดเพื่อน + ADD = ส่งคำขอ / รายชื่อเพื่อน (จุดเขียว = ออนไลน์, บอกว่าอยู่ล็อบบี้หรือห้องไหน, ออฟไลน์บอกเห็นล่าสุดกี่นาทีก่อน)
  - อยู่ในห้อง → ปุ่ม INVITE ชวนเพื่อน / อยู่ล็อบบี้ + เพื่อนอยู่ในห้อง → ปุ่ม JOIN เข้าห้องเพื่อน / X สองครั้ง = ลบเพื่อน
- **REQUESTS**: คำขอเป็นเพื่อน ACCEPT / DECLINE
- **GUILD**: สร้างกิลด์ (500 เหรียญ ชื่อ 3-20 ตัว + TAG 3-5 ตัว A-Z/0-9 ห้ามซ้ำ) หรือเข้าด้วย TAG / ดูสมาชิก (สูงสุด 20) / GUILD CHAT / LEAVE (หัวหน้าออก = ยกให้คนถัดไป, คนสุดท้ายออก = ลบกิลด์) / ชื่อในห้องรอมี [TAG] นำหน้า
- **CHAT**: แชทรวม (GLOBAL) และแชทกิลด์ 30 ข้อความล่าสุด อัปเดตทันที / จำกัด 120 ตัวอักษร ส่งได้ทุก 1.5 วิ / กรองคำหยาบพื้นฐาน (แก้รายการคำได้ใน Social.cs)

**ห้องรอ**: ปุ่ม `INVITE FRIENDS` (ใต้ COPY CODE) เปิดรายชื่อเพื่อนเพื่อกด INVITE
**คำชวน**: เพื่อนชวน → กล่องเด้ง "X invites you to room 123456" กด JOIN / IGNORE (หมดอายุ 3 นาที)
**สถานะออนไลน์**: ใช้ Firebase OnDisconnect — ปิดเกม/เน็ตหลุด server ตั้งเป็นออฟไลน์เอง
**ดูคนอื่นเล่น (Spectate)**: ใช้ได้เมื่อตกรอบ/หมดชีวิตในโหมด Battle Royale / Survival / Campaign (เฟส 7B) — การเข้าไปดูห้องที่กำลังแข่งอยู่จากข้างนอกยังไม่ทำ (ห้องปิดตอนแข่ง ต้องเพิ่มช่องผู้ชมใน Photon)

**ข้อมูลใน Firebase**: `friend_codes`, `friends`, `friend_requests`, `presence`, `invites`, `chat`, `guilds`, `guild_tags`, `users/{uid}/guild`
- Firebase Rules ต้องอนุญาตให้ผู้ที่ล็อกอินอ่าน/เขียน path เหล่านี้ (ถ้า Rules ตอนนี้เป็น `auth != null` อยู่แล้วใช้ได้เลย)

**ไฟล์**: Social.cs (ใหม่ ข้อมูล+Firebase), LobbyManager.Social.cs (ใหม่ หน้าจอ+กล่องคำชวน+ช่องพิมพ์), LobbyManager.cs ([TAG] หน้าชื่อ)
**สวิตช์**: `Social`, `Chat`, `Guilds`

**เช็คลิสต์ทดสอบ** (2 บัญชี/2 เครื่อง)
1. เครื่อง A กด SOCIAL → COPY โค้ด / เครื่อง B ใส่โค้ด → ADD → เครื่อง A เห็นวงแดง → REQUESTS → ACCEPT
2. ทั้งสองเห็นกันใน FRIENDS จุดเขียว ONLINE / IN LOBBY
3. A สร้างห้อง → INVITE FRIENDS → INVITE → B เห็นกล่องชวน → JOIN → เข้าห้องเดียวกัน
4. CHAT → พิมพ์ข้อความ เห็นทั้งสองเครื่อง
5. A สร้างกิลด์ (เหรียญลด 500) → B เข้าด้วย TAG → ห้องรอเห็น [TAG] หน้าชื่อ → GUILD CHAT
6. ปิดเกมเครื่อง B → A กดดู FRIENDS (รอ ~20 วิ) ขึ้น OFFLINE
