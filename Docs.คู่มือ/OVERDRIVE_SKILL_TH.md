# OVERDRIVE — สกิลเร่งอาวุธ

สกิลลำดับที่ 8 (index 7) เลือกจากโรงเก็บยาน > สกิล > OVERDRIVE > ติดตั้ง ปลดล็อกเลเวล 11 เมื่อเปิดระบบเลเวล คูลดาวน์พื้นฐาน 18 วินาที

ลดระยะห่างระหว่างนัดลงครึ่งหนึ่งเป็นเวลา 5 วินาที ดาเมจต่อนัดเท่าเดิม ใช้ได้กับอาวุธทุกแบบ ใช้เวลาบัฟร่วมกับไอเท็ม OVERDRIVE จึงไม่คูณซ้ำและไม่ลดเวลาไอเท็มที่เหลือมากกว่า 5 วินาที

เพิ่มต่อท้าย Catalog เพื่อรักษา index สกิลเดิม บันทึกและส่งสกิลผ่านระบบ loadout เดิม ใช้ไอคอนไอเท็มเร่งยิงที่มีอยู่ บอทใช้เมื่อเล็งยิงศัตรูในระยะและยังไม่มีบัฟ วงพลังงานสีส้มแสดงผ่าน RPC และซ่อนเมื่อยานตาย จบแมตช์ หรือศัตรูมองไม่เห็นจากล่องหน
