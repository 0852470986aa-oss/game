# แก้โหลดคลังยานและบันทึกเหรียญ — 14 ตุลาคม 2026

## หลักฐานและสาเหตุที่พบในโค้ด

- Editor.log มีข้อความ `Coin balance is missing or invalid.` ยังไม่ได้ยืนยันว่าเป็นปัญหาเครือข่ายหรือข้อมูลบนเซิร์ฟเวอร์จริง
- GetUnlockedShips เดิมคืน [0] เมื่ออ่านล้มเหลว ทำให้ Lobby มองว่าโหลดสำเร็จและเหลือยานเริ่มต้น จึงไม่เข้าเส้นทางลองโหลดใหม่
- การสร้าง/เติมข้อมูลบัญชีเดิมส่งคำสั่งเขียนแล้วเรียก login success ทันที โดยไม่รอเขียนเสร็จ
- ยอดเงินเดิมยอมรับเฉพาะข้อความจำนวนเต็ม ไม่รองรับค่าตัวเลขจำนวนเต็มในรูป 5000.0 หรือ scientific notation

## การแก้ไข

- รอเตรียมบัญชีเสร็จก่อน login success หากอ่าน/เขียนล้มเหลวแสดงข้อผิดพลาด ไม่ข้ามเข้าล็อบบี้ด้วยข้อมูลไม่พร้อม
- สร้างบัญชีและเติม field ด้วย transaction ตรวจข้อมูลล่าสุดก่อนเขียน ไม่เขียนทับ field ที่มีอยู่แล้ว
- โหลดเหรียญ รายการยาน ยานที่เลือก และสกิลจาก snapshot เดียวกัน
- โหลดล้มเหลวจะรักษารายการเดิม ปิดการใช้งานระหว่างรอ และลองใหม่ ไม่สร้างข้อมูลเป็นยานเริ่มต้นแทน
- ตรวจตัวเลขแบบไม่ยอมรับค่าติดลบ เศษส่วน NaN หรือเกิน long แต่รับค่าจำนวนเต็มรูปแบบตัวเลขของ Firebase
- เพิ่มเหรียญพร้อม receipt ที่ `users/{uid}/coin_operations/{operationId}` ใน transaction เดียว ลองซ้ำสูงสุด 3 ครั้งด้วย ID เดิม ไม่บวกซ้ำเมื่อ acknowledgement หาย
- รออ่านข้อมูลจริงก่อนบวกเหรียญ ไม่ใช้ศูนย์แทนยอดที่อ่านไม่ได้ และไม่ส่ง callback สำเร็จข้ามบัญชี
- หากกด Play ตรง LobbyScene โดยไม่มี FirebaseManager จะแจ้งให้เริ่ม LoginScene เพื่อโหลดของในบัญชี

## ขอบเขตและข้อจำกัด

- ไม่มีการล้างบัญชี รีเซ็ตเหรียญ หรือซื้อยานเพื่อทดสอบกับบัญชีจริง
- Receipt ป้องกันซ้ำภายในการ retry ของคำสั่งเดียว ยังไม่ใช่คิวถาวรข้ามการปิดเกม/Stop Play; ควรรอให้บันทึกเสร็จก่อนหยุด
- ต้องตรวจ Firebase Rules จริงว่าอนุญาต transaction และ child coin_operations ในบัญชีเจ้าของ ผู้ช่วยไม่ได้แก้ Rules หรือเชื่อมบัญชีจริง
- การทดสอบออฟไลน์ไม่สามารถยืนยัน permission/การเชื่อมต่อจริงได้
- งานแอนิเมชันแยกชิ้นส่วนสกินยังไม่ได้เริ่ม ตามลำดับที่ผู้ใช้ให้แก้ข้อ 2 ก่อน

## ทดสอบใน Unity

1. รอคอมไพล์เสร็จ เปิด LoginScene แล้วล็อกอินบัญชีเดิม ตรวจรายการยานและยอดเงิน
2. เล่นจบหนึ่งแมตช์ รอสักครู่ก่อนกลับล็อบบี้ ตรวจยอดเงินและยานที่เคยซื้อ
3. ลองใหม่อีกครั้ง หากยังมีข้อผิดพลาด ส่งข้อความ `Coin save attempt ...` จาก Console เพื่อแยก permission กับปัญหาโหลดข้อมูล
