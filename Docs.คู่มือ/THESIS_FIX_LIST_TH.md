## ระดับ 3 — บทที่ 3–4 ที่ยังตามระบบไม่ครบ

1. **พจนานุกรมข้อมูล (3.2.3) มี 6 ตาราง** (ผู้เล่น, ยาน, สกิล, การติดตั้ง, ประวัติแมตช์, ยานที่ครอบครอง) แต่แผนภาพ DFD ใช้ที่เก็บข้อมูลถึง **D9** — ควรเพิ่มตารางของ D5 คลังไอเท็ม/ตีบวก, D6 สังคม (เพื่อน กิลด์ แชท), D7 ภารกิจ/เลเวล, D8 แรงค์/ตารางอันดับ, D9 การตั้งค่า
   ข้อมูลจริงใน Firebase ที่เพิ่มมา: `users/{uid}` (username, callsign, coin_balance, unlocked_ships, high_score, total_wins/losses …) + JSON ความก้าวหน้า (เลเวล XP ภารกิจ Achievement ประวัติ ฉายา) + JSON เศรษฐกิจ (ตีบวก ไอเท็ม ร้านรายวัน) + `leaderboard/{uid}` (name, mmr, level, at) + `chat/…`, `dm_notify/…`, `feature_flags/…`
2. **ตารางผลทดสอบบทที่ 4 มี 7 หมวด** (ล็อกอิน, Lobby, คลัง, สร้างห้อง, รอจับคู่, แข่งขัน, ตั้งค่า) แต่บทที่ 1 และสตอรี่บอร์ด 25 ซีนมีระบบมากกว่านั้น — ควรเพิ่มตารางทดสอบ: ร้านค้า/ตีบวก/กล่องเสบียง/ขายไอเท็ม, ภารกิจ+โปรไฟล์, แรงค์+ตารางอันดับ, สังคม (เพื่อน แชท กิลด์), โหมดพิเศษ 4 โหมด, เนื้อเรื่อง 5 ด่าน, เงื่อนไขชนะ, กลับเข้าแมตช์เมื่อเน็ตหลุด
3. **ตาราง 4.5 ข้อ 1** คาดหวัง "ภาพตัวอย่างสมรภูมิ (Obelisk Plains of Prism)" → ภาพตัวอย่างแผนที่ปริซึมเปลี่ยนแล้ว แก้คำอธิบาย/ภาพให้ตรง

## ระดับ 4 — ภาพประกอบที่น่าจะเก่า (ตรวจด้วยตาแล้วถ่ายใหม่)

หน้าตาเกมเปลี่ยนเมื่อ 7–9 ต.ค. — ภาพจับหน้าจอที่ถ่ายก่อนวันนั้นจะไม่ตรง:
- หน้าเมนูหลัก (ตอนนี้ภาษาไทย ปุ่ม จับคู่ด่วน / เลือกโหมด / โรงเก็บยาน / แรงค์)
- หน้าเลือกวิธีเล่น (การ์ดรูปภาพ: เนื้อเรื่อง / ต่อสู้แบบทีม / ตัวต่อตัว / 1 ต่อ 1 / โหมดพิเศษ)
- หน้าเตรียมพร้อมรบ (แบบช่อง VS) และหน้าตั้งค่า (หน้าเดียวเลื่อนได้)
- ปุ่มตั้งค่า + อีโมตในสนาม (ย้ายมาแถวเดียวมุมขวาบน)
- แผนที่ปริซึมทุกภาพ (ภาพประกอบที่ 1.18 และภาพในสตอรี่บอร์ด/ผลทดสอบ)
- ภาพสกิลล่องหน (มีออร่าม่วงและแสงวาบชุดใหม่)

ภาพ "ต้นแบบหน้าจอ" (3.2.5 ภาพประกอบที่ 3.17–3.23) เป็นภาพออกแบบ ไม่จำเป็นต้องตรงเกมจริง เก็บไว้ได้
