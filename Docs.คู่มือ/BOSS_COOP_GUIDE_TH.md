## เข้าเล่นอย่างไร

- เล่นคนเดียว: เลือกวิธีเล่น → SPECIAL MODES → BOSS CO-OP → VS BOT จะได้บอทฝ่ายเรา 3 ลำ
- ออนไลน์: สร้าง/เข้าห้อง → ตั้งค่าห้อง → กดเปลี่ยนโหมดเกมจนเป็น BOSS CO-OP → ให้ผู้เล่น 2–4 คนกดพร้อม → Host เริ่ม
- ออนไลน์ไม่เติมบอทอัตโนมัติ ทุกคนอยู่ฝ่ายเดียวกัน และขนาดห้องจำกัด 4 คน
- ทุกเครื่องต้องใช้ build ที่มีโหมดนี้เหมือนกัน
- ปิดทางเข้าโหมดใหม่ได้ด้วย `FeatureFlags.BossRaid = false` ไม่ควรสลับสวิตช์ระหว่างแมตช์

## กติกา

- คนละ 3 ชีวิต เวลาเริ่มต้น 8 นาที (Host ออนไลน์ยังปรับเวลาในห้องได้)
- บอสตาย = ชนะ คนจริงที่ยังอยู่ในแมตช์หมดชีวิตทั้งหมด หรือเวลาหมด = แพ้
- บอทฝ่ายเราเกิดใหม่ได้ไม่เกิน 3 ชีวิต บอสและลูกน้องไม่เกิดใหม่
- หากคนจริงหมดชีวิตทั้งหมด จะไม่รอให้บอทฝ่ายเราสู้ต่อจนหมดเวลา
- HP บอสใช้จำนวนคนจริงตอนเริ่ม + บอทฝ่ายเรา จำกัด 1–4 ลำ: ตัวคูณ 8 / 12 / 16 / 20 เท่าของยานบอส
- HP ไม่ลดลงตามจำนวนคนที่หลุดระหว่างแข่ง
- เฟส 1: HP มากกว่า 66% ยิงกระสุนกระจาย 5 นัด
- เฟส 2: HP 33–66% สลับกระสุนกระจายกับเลเซอร์กวาด เรียกลูกน้อง 2 ลำ
- เฟส 3: HP ไม่เกิน 33% เลเซอร์ถี่ขึ้น เคลื่อนที่เร็วขึ้น เรียกลูกน้องเพิ่ม 3 ลำ
- เตือนแนวโจมตีล่วงหน้า 1.25 วินาที เลเซอร์กวาดนาน 2 วินาที (เลเซอร์ปัจจุบันทะลุสิ่งกีดขวาง ต้องหลบออกด้านข้าง)
- ชนะ 200 เหรียญ แพ้ 15 เหรียญ ผ่านระบบผลเกมเดิม; XP และ Pass XP ใช้ระบบเดิม ไม่เพิ่มซ้ำอีกชุด
- ชนะมีโอกาส 10% ได้ตั๋วสุ่มสกิน 1 ใบ ถ้าเปิด SkinGacha; Host สุ่มหนึ่งครั้งต่อแมตช์ ทุกคนใช้ผลเดียวกัน
- รางวัลยังเป็นระบบฝั่ง client เช่นเดียวกับโปรเจคเดิม ไม่ใช่การป้องกันโกงระดับเซิร์ฟเวอร์

## เครือข่าย

Host คุมบอสและลูกน้อง ใช้ยาน Photon Room Object เดิม เมื่อเปลี่ยน Host เครื่องใหม่รับช่วงยานเดิม
สถานะ `Raid.*` ใน Room Properties เก็บเฟส เวลา/มุมโจมตี การเรียกลูกน้อง ผลสุ่มตั๋ว และ BattleToken ของรอบ
ทุกเครื่องวาดสัญญาณเตือนด้วย Photon time เดียวกัน มีเฉพาะ Host ที่ส่งดาเมจเลเซอร์
บอสที่หายไประหว่างการเริ่มสร้างมีช่วงรอ 8 วินาทีให้ Host ใหม่กู้การเกิด
การกลับเข้ารอบเดิมไม่ล้างสถานะ Raid; เริ่มรอบใหม่ล้างค่ารอบเก่า

## ตรวจแล้ว / ยังต้องตรวจ

ผ่านแล้ว:

- Unity คอมไพล์ไฟล์โหมดใหม่และการเชื่อมกับระบบเดิม
- `Tools → Battlefield → Validate Boss Co-op Rules` ตรวจ 20 ข้อ: เลขโหมด ตารางเมนู ขอบเขตเฟส HP ชีวิต และกติกาโหมดเดิม
- ห้องออฟไลน์แยกจาก Firebase: คน 1 + บอทฝ่ายเรา 3 + บอส 1, ทีมถูกต้อง, บอส HP 3000 ในชุดทดสอบ
- เห็นเฟส 2 และ 3 พร้อมลูกน้อง 2 และ 3 ลำ โดยไม่เกิดซ้ำทุกเฟรม
- จำลองบอสตายแล้วได้ `ModeResult = 1`
- บอส/ลูกน้องเกิดใหม่ไม่ได้ และบอทฝ่ายเราหมดชีวิตแล้วเกิดใหม่ไม่ได้
- ดูภาพแถบเลือดจริง และปรับไม่ให้ทับข้อมูลเวลา/ชีวิต

ยังไม่ยืนยัน:

- แพ้เพราะหมดชีวิต / หมดเวลาและหน้าผลครบวงจร (Unity ปิดก่อนจบการทดสอบรอบสอง)
- ออนไลน์จริง 2–4 เครื่อง ความตรงกันของ HP/เลเซอร์ และการเปลี่ยน Host/กลับเข้าห้อง
- รอบเล่นซ้ำ การแจกเหรียญ/XP/Pass XP/ตั๋วจริง และการกลับ Lobby
- Android build และความอ่านง่ายบนจอมือถือหลายขนาด
- ทดสอบซ้ำข้อผิดพลาดข้อความ KILL หลังแก้ `EditableTemplate.Spawn` จาก DestroyImmediate เป็น Destroy ตอนเล่น

ห้องทดสอบไม่ได้ล็อกอิน Firebase และระงับการรายงาน Progress/ตั๋วก่อนทดสอบผล ไม่ได้ใช้บัญชีจริงรับรางวัล

## เช็กลิสต์ก่อนส่งงาน

1. เปิด Unity รอคอมไพล์ ตรวจ Console ไม่มี error ใหม่
